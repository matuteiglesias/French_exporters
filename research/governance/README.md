# Research governance

This repository is operated as a role-separated virtual research laboratory under Matías Iglesias as Principal Investigator.

## Stable rules

- One active research-output front at a time.
- Preserve claim → evidence → input/version → method → output → review provenance.
- Distinguish primary evidence, source claims, derived results, inference, and speculation.
- AI- and Codex-produced artifacts enter REVIEW by default.
- Codex implements bounded engineering specifications; it does not choose scientific meaning, substitute data, change estimands, or make publication claims.
- External communication, submissions, authorship, data release, interpretation, and research-direction decisions require PI approval.
- Every run must leave inspectable evidence, an artifact/state change, a defensible challenge, or a justified no-intervention result.
- Every task must define an observable completion condition and one exact restart pointer.

## Change control

This is a frozen v0.1 baseline. Revise by creating a new version with the previous version, date, requester, reason, changed sections, and operational/scientific effect. Do not silently overwrite accepted governing decisions.
